1. IMPORT THE SEEDER:
   ─────────────────────────────────────────────────────────────────────────
   Method A - MySQL Command Line:
   $ mysql -u root -p your_database < database_seeders/user_seeder.sql

   Method B - phpMyAdmin:
   • Open http://localhost/phpmyadmin
   • Select your database
   • Import → Choose file → user_seeder.sql → Go

2. LOGIN TO APPLICATION:
   ─────────────────────────────────────────────────────────────────────────
   URL: http://localhost/montera-app/auth/login

   Use any of the credentials above

3. TEST DIFFERENT ROLES:
   ─────────────────────────────────────────────────────────────────────────
   • Login with each user to see different access levels
   • Verify redirects work correctly based on role
   • Test permission system across modules

╚════════════════════════════════════════════════════════════════════════════╝

Login Not Working?
──────────────────────────────────────────────────────────────────────────────
✓ Check user status is 'Aktif' in database
✓ Clear session files in application/cache/sessions/
✓ Verify .env database credentials are correct
✓ Check Auth controller supports password_hash() format

Permission Denied?
──────────────────────────────────────────────────────────────────────────────
✓ Verify user_roles table has role assignment
✓ Check modules table has required modules
✓ Verify role_permissions table grants access
✓ Check permission library is loaded

Duplicate Entry Error?
──────────────────────────────────────────────────────────────────────────────
✓ Users already exist - delete first or use UPDATE statements
✓ See generate_password_hashes.php for UPDATE queries
